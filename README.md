# Agnivesh Das: portfolio

Data Analytics & AI Leader · Walmart · BP · Nike

Live site: https://agnidas31.github.io/Agnivesh-Das/

Everything on the site and the résumé PDF is generated from two content files:

- `content.py`: profile, summary, signature results, capabilities, experience, education
- `site_content.py`: site settings and the list of project case studies (one repo per project)

Build with `python3 build.py all`. See `PORTFOLIO.md` for how the site is maintained.
